# renjuportal-mobile-releases

Release builds of the RenjuPortal mobile app for Android.

Each release holds the APK and `latest.json`, which the app reads to find a newer build.
The source code is not published here.

The APKs are signed with a debug key and are not for store release.

---

RenjuPortal モバイルアプリ（Android）の配布用リポジトリです。

各リリースに APK と `latest.json` を置いています。アプリは `latest.json` を読んで、新しい版を見つけます。
ソースコードはここにはありません。

APK はデバッグ鍵で署名したもので、ストア公開用ではありません。
